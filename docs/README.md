skill pack is deployed from** — file for file, the sections `get_skill_pack` serves over MCP.

publish a docs folder that has drifted from the pack. A section is here because it is in the
pack; a section missing here is missing there too.

next; write against `api-replicad`; load the domain section that matches the thing being
built. Anything a section tells you to CHECK, the local engine checks — `axle build` runs the
